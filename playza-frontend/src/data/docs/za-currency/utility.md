
# $ZA Utility & Value

Every unit of $ZA has clear, usable value inside the Playza ecosystem. This page lists **everything you can do with $ZA today** — and where it's headed.

## What $ZA unlocks

| Use case | Description |
| --- | --- |
| ⚔️ **Enter H2H matches** | Pay the entry fee, compete against another player, winner takes the pool. |
| 🎯 **Play SoloEarn** | Pay to attempt a target score; beat it and earn $ZA back with a reward. |
| 🏆 **Join Tournaments** | Enter multi-player contests with dynamic prize curves. |
| 🕹️ **Compete in Games** | Enter time-based leaderboard contests. |
| 🏦 **Withdraw to local currency** | Convert $ZA back to cash via Paystack, Opay, or bank transfer. |
| 🎁 **Refer friends** | Earn $ZA when verified referred players join and play. |

## $ZA is 1:1 with a fixed rate

$ZA is not a speculative asset today. Its value is a **fixed conversion**:

> 1,000 $ZA = ₦1,000 = ~$0.73 USD

This is the same rate for deposits and withdrawals.

## What $ZA doesn't do (today)

To be crystal clear about what $ZA is **not** doing right now:

- $ZA is **not traded** on any exchange (Q4 2026 target for exchange listing).
- $ZA is **not** currently transferable between random Playza accounts as a general payment rail. Movement happens through contests, referrals, and withdrawals.
- $ZA is **not** a security or an investment product.
- $ZA is **not** the same as PZA Points — see [PZA Points & Loyalty](/doc/loyalty/overview) for the loyalty program.
